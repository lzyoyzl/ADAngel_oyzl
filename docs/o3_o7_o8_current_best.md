# A100 O3 / O7 / O8：当前最佳已验证候选

## 结论与适用范围

当前保留 **O3：候选22；O7/O8：候选23**。这是相对各自旧正式实现的优化，
不是相对O0/O5/O6的加速比。正式默认尚未切换，RTX 5090后端不变。
以下只使用完整24样本结果，不拼接不同轮次的最快值；失败或较慢的新候选不替换本表。

共同配置为CTA `64×128×128`、4个consumer warp、原生两路INT4 MMA、寄存器partial、
独立G128 scale和FP32输出。B fragment在两个M方向MMA片段之间复用；
O3采用两阶段、O7/O8采用三阶段`cp.async`流水线。group累加顺序保持不变。

## 1. Compute-only / GEMM-only：当前主要比较

v19同一binary、24个真实样本、5轮换序配对；每次预热50次、测量200次。
先在同样本同轮计算加速比，再按样本汇总，故不必等于两列总体median直接相除。

|后端|最佳候选|旧默认 median ms|候选 median ms|配对加速比|吞吐提升|延迟降低|
|---|---:|---:|---:|---:|---:|---:|
|O3|22|0.568576|0.539648|1.05399×|5.40%|5.12%|
|O7|23|0.607232|0.541696|1.12098×|12.10%|10.79%|
|O8|23|0.610304|0.543744|1.12113×|12.11%|10.80%|

配对加速比的描述性bootstrap 95%区间：O3 `[1.05159,1.05660]`、
O7 `[1.11670,1.12313]`、O8 `[1.11954,1.12451]`。
24样本来自同一trace，不是24次独立模型实验。

## 5. 正确性与MSE

v19的24样本候选输出与各自旧实现**逐位相同**；候选相对旧实现的MSE为0。
下表是24个输出矩阵各自MSE的median/mean，不是权重MSE，也不是模型任务精度。

|后端|FP16组内参考|Median MSE|Mean MSE|优化造成的MSE变化|
|---|---|---:|---:|---:|
|O3|O0|0.006653010285|0.007578847011|0|
|O7|O5|0.005536172427|0.005053635834|0|
|O8|O6|0.004411084949|0.004381379215|0|

这三个MSE的参考输入不同，不能直接比较数值大小来推断哪个格式普遍更准确。
原生U4×S4/S4×S4及异步搬运已进行同kernel指令审计；有spill，如实记录，不宣称零spill。

## 6. 结果限制与继续优化方向

GPU共享、未锁频，全部CV失败记录均保留。v19候选compute记录CV≥3%的数量分别为
O3 `46/120`、O7 `38/120`、O8 `54/120`。v17候选cold/steady总延迟的对应数量分别为
O3 `13/72、57/72`，O7 `8/72、45/72`，O8 `11/72、51/72`；转换total均为`0/72`。
因此这是当前条件下的配对结果，**不等同于所有阶段均满足CV<3%的严格验收**。

当前约0.54ms仍高于理想资源容量模型下界；模型下界假设理想重叠，不是可保证达到的时间。
后续重点是同时控制依赖链、临时值数量、寄存器压力和指令发射，不把“消除一条依赖”
等同于“整体一定加速”。v21已完成独立P×S后四项树、全部32项树及及时合并复用临时值测试；
数值通过但均显著变慢，故本表最佳组合不变。下一步优先减少运行时phase控制和片段级临时存储。
每版的实测收益、负结果、MSE和采纳决定单独记录于[迭代简报](o3_o7_o8_iteration_summary.md)。
