# v45：当前G128-major kernel的固定尺寸特化

状态：A100编译、审计、安全检查、24样本初筛、NCU及独立确认已完成；未确认收益，不采用。
完整结果见 [v45证据](evidence/a100_o378_roof_v45/README.md)。O7/O8方案1独立确认均约+0.20%，
95%区间触及1；O3和方案2退化。当前最佳仍为54/59，正式默认不变。

v44减少spill却增加动态地址/控制指令，O7/O8退化，O3微小正向未通过独立确认。
本轮从54/59重新出发，不叠加v44改写，测试编译期尺寸能否消除真实stride工作。

|方案|编译期信息|K循环|
|---|---|---|
|0|原54/59运行时尺寸|原结构；要求编码SASS与最佳相同|
|1|M=N=4096，K仍为运行时参数|原结构|
|2|M=N=K=4096|显式unroll 1，避免展开整个32组循环|

所有方案通过同一仅支持4096³的原生Driver/CUDA Event接口运行，拒绝其他尺寸，不静默回退。
指针保持64bit；共享布局、CTA64×128×128、4warp、O3三阶段/O78两阶段、独立G128 scale、
原生两路INT4、FP32数学顺序及转换不变。两份独立header只添加K循环unroll 1提示，
不改数学或搬运表达式。与v20不同：当前使用G128-major payload，O3有行scale后移，
O7/O8有异步FP32 scale搬运；v20的旧布局结果不能直接替代本轮验证。

先编译和同entry指令/资源审计，保留失败或无收益结果。
需要实际4096³的随机/零/极值/不同组scale检查、非默认stream、FP64语义参考、逐位54/59对照，
及native拒绝尺寸验证；安全检查不得以小矩阵代替固定尺寸kernel。
racecheck限定 `--kernel-name kns=adangel_roof_fixed_dims_`，检查真实4096³的两个目标entry，
不插桩PyTorch/FP64参考kernel；参考数值计算仍执行。未限定的初次racecheck包含参考计算插桩，
观察到高CPU/内存使用后主动中止，保留日志，不记为通过。memcheck/synccheck不采用该过滤。
审计与数值通过后，24样本×3轮×3后端×3方案，warmup50/repeats200，
同进程循环换序，无过滤。记录MSE和CV失败；正向候选需独立确认后再考虑四模式接口。
NCU用于核对真实MMA/I2F工作、地址/控制指令和等待，不以静态指令数或零spill代替性能。

本轮不重建正式扩展、不改默认、不改5090，也不重启magic-bias或实施待确认的跨G128整数累加。
