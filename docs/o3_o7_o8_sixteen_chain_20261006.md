# O3 / O7 / O8：16 链 MMA 调度测试（v92）

## 结论

**不采纳 v92；最佳仍是 O3 v89、O7/O8 v78 GEMM + v73 准备，正式默认和 5090 不变。**
本轮增加 MMA 交错链并减少部分静态指令，但完整 24 样本首测和复测均未取得收益。
输出逐位一致、MSE 未变。共享 GPU 有其他 CUDA 进程，且多数记录 CV 超标；
因此报告原始负向趋势，不把百分比冒充隔离环境下的精确硬件成本。

## 1. 实际改变了什么

保持 CTA `64×128×128`、128 线程、两路原生 U4/S4 和 S4/S4、各 G128 的 factor、
全 K 安全整数累加及回退、FP32 最终输出和转换不变。
O3 保留当前最佳的分组 CTA 顺序和三阶段；O7/O8 保留两阶段和 v73 准备。

原来顺序处理两个 N64 寄存器片段，每片段有 8 条 high/high/low/low MMA 链；
候选将整个 N128 片段同时保留，安排 16 条链。partial 从每线程 32 个变为 64 个整数寄存器，
最终输出 accumulator 仍为每线程 64 个。高位结果乘 16 后作为低位 MMA 的 C 输入，
每个输出内的整数运算顺序和 scale 数值不变。

|编译与资源|O3 对照 → 候选|O7/O8 对照 → 候选|
|---|---|---|
|分配寄存器 / 线程|168 → 214|168 → 230|
|最大驻留 CTA / SM|3 → 2|3 → 2|
|整数热循环静态指令|323 → 309|383 → 369|
|每组原生 INT4 MMA|64 → 64|64 → 64|
|每组 LDSM|16 → 16|16 → 16|
|程序中已开始、未完成的 MMA 链峰值|8 → 16|8 → 16|
|候选 local allocation|0 B|0 B|

同 entry PTX/SASS 原生 INT4 与异步 copy 审计通过；对照的编码指令与原最佳完全一致。
16 是静态程序交错链数，不是测到的硬件并发度。最大驻留能力由实际 CUfunction 资源查询得到，
不是运行中的 occupancy 采样。候选 launch bound 为 `128,2`；本轮是寄存器/片段/调度的组合取舍，
不能把性能差当作严格单因素的“增加链数成本”。

## 2. 完整 24 样本结果

每个后端 24 样本 × 3 轮；预热 1000、正式 200、conversion inner=100。
同进程同输入交错配对、单 CUDA stream，直接测试全部真实数据，没有小样本性能初筛。
首测与复测各自完整保留，共 864 条记录；不删离群、不选择较好轮次覆盖首测。

## 3. 正确性与 MSE

所有真实输出对相应对照逐位一致，优化新增 MSE 为 0；以下误差来自既有格式转换，未因本轮变化。

|后端|误差参考|24 样本 MSE median|24 样本 MSE mean|
|---|---|---:|---:|
|O3|O0|0.006653010287410|0.007578847013303|
|O7|O5|0.005536172273439|0.005053635851003|
|O8|O6|0.004411084910986|0.004381379299074|

有限 GPU 数值检查覆盖零、随机、符号/饱和值、不同 scale、非默认 stream、
安全/回退混合及四种模式；O3 为 96 项 + 8 项拒绝 + 2 项坐标检查，
O7/O8 为 64 项 + 12 项边界 + 8 项混合/尾部检查，每次测试均通过。
O8 仍仅 `layer_24_o_proj` 的 12 个 CTA 按既有安全界回退。
本轮未新增 NCU 或 sanitizer，不将旧版检查冒充本轮全面内存安全证明。

## 4. 对下一步的约束

增加交错链不是免费收益：本轮实际扩大了 partial/B fragment 的存活范围，
寄存器增加、最大驻留能力下降，而必要 MMA/供数工作没有减少。
两个完整测试都未显示收益，因此停止这一个固定候选，不继续扫描更多链数/片段宽度。
没有新 NCU，不能断言退化全部由 occupancy 引起，更不能认为已证明 8 链是所有算法的最优值。

当前必要 MMA 容量下界约 0.220347 ms，仍是 1410 MHz、理想重叠的乐观模型；
本轮没有减少必要 MMA 工作，也没有达到该目标。后续应在当前寄存器预算内减少实际工作或改善就绪度，
不能单独追求零 spill、静态指令减少或更多逻辑交错链。
转换代码没有变化；未扩展负收益候选的 conversion/Cold/steady 性能测量，
不宣称新的端到端收益或精确退化幅度。
