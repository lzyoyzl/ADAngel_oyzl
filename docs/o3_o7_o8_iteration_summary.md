# O3 / O7 / O8 优化迭代简报

只记录完成的实测结果；设计/编译中明确标为待测。不同binary/轮次不拼接最佳值。
默认未切换；共享、未锁频GPU，保留CV失败记录。以下“提升”指配对吞吐提升，
正数更快、负数更慢；延迟降低使用 `1−1/speedup`，不要与吞吐提升混称。
