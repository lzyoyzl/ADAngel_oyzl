# O3 / O7 / O8 优化迭代简报

记录实测及编译筛选结论；未进行GPU测试的候选明确标注，不杜撰性能/MSE。不同binary/轮次不拼接最佳值。
默认未切换；共享、未锁频GPU，保留CV失败记录。以下“提升”指配对吞吐提升，
正数更快、负数更慢；延迟降低使用 `1−1/speedup`，不要与吞吐提升混称。

独立24样本四模式：Cold **+1.13%/+1.10%**，steady **+1.00%/+1.16%**；转换未变。
720条结果对v67输出逐位一致；24样本MSE median O7/O5=0.005536172273439、O8/O6=0.004411084910986。
168regs/3CTA不变；整数循环指令378→383，IMMA/LDSM不变，候选零spill。

大量CV失败保留，不能宣称严格稳定验收；保留独立候选，不切默认、不改O3/5090，不跨轮累计百分比。
