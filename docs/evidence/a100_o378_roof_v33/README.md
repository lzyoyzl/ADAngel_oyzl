# v33：有界 unsigned 寻址，O7/O8 小幅刷新 GEMM 最佳

## 方法与边界

59/60以55/56为同stage对照，只将device body的m/n/k/total_n参数从int改为uint32_t。
公共kernel签名不变；保留CTA64×128×128、4warp、两/三阶段cp.async、G128-major布局、
两路原生INT4、scale乘法和升序G128 FP32 FMA。partial仍是有符号INT32，输出为FP32。
没有magic-bias、跨组INT32累加、量化变化或数学重排。正式默认及5090均不变。

host明确限制正尺寸、M64/N128/K128对齐、`M*K,N*K,M*N<=INT32_MAX`及grid范围。
这是有界的元素寻址类型优化，不是将GPU指针截为32bit。边界/对齐测试和有限GPU安全检查通过。

每轮warmup50/repeats200，同binary循环换序，不删除离群或CV失败记录。

## NCU：收益小在哪里

以下为同binary、相同profiling口径的O7诊断；NCU时间不能代替正式CUDA Event时间。

|指标|56，三阶段|59，两阶段|60，三阶段|
|---|---:|---:|---:|
|NCU duration ms|0.442848|0.441312|0.441536|
|动态warp指令|118,767,616|116,285,440|117,202,944|
|IMMA / I2F / FMUL / FFMA，各自|16,777,216|16,777,216|16,777,216|
|LDSM|4,194,304|4,194,304|4,194,304|
|Local理论sectors|4,063,232|2,097,152|4,063,232|
|可驻留CTA上限|3|3|3|

59总指令比56少2.09%，local理论访问减少；但数学指令和shared主要工作量没有减少。
60对同三阶段56仅少1.32%指令，没有确认Event收益。不能把全部59收益归因于unsigned一项。
O8同样趋势。PC采样显示wait/math仍占较多未发射样本；该占比不是运行时间占比。
必要容量下界仍约0.220347ms@1410MHz，主要受MMA/I2F工作量约束，**不是已达到或保证可达**。
