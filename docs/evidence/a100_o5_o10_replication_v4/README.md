# 当前构建：24 样本、三轮 Compute-only 复测

目的：确认加入内部 swizzle 候选后的当前构建，选定后端的数值与性能趋势仍成立。
这是预先固定三轮的独立复测，不是重测直到 CV 过线；不替换首轮四模式的任何记录。

- 源码：`1108e5967947d8c902f4c0d28ccb88cde0f75328`。
- Binary SHA256：`36e59a1d34c226970ba0a5355c2988190b22f0d548c3e8813b32b7bd9477878c`。
- 原始 FP16 来源、源格式、CTA 和 scale 布局同 v3；**没有启用 swizzle 候选**。
- 24 样本×3 轮×9 条路径=648 条 compute-only 记录，其中 432 条属于 O5–O10。
- warmup=50，repeats=200，inner=100；共享、未锁频 A100，没有其他由本任务启动的并发 GPU 测量。
- 24 样本数值检查全部通过；O9==O7、O10==O8 的 FP32 输出逐位一致。
- 与 v3 比较，O7/O8/O9/O10 的 96 个逐样本组内 MSE 完全相同。
