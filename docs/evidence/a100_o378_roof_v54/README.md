# v54：向量转换接入 O7/O8，验证实际端到端收益

**本轮优化conversion，不优化GEMM；正式默认及5090实现不变。**
固定16元素转换接入内部候选5，与原最佳标量转换4同进程配对，
两者执行完全相同的GEMM59。没有新的量化、scale乘法顺序或FP32求和重排。

## 实现与计时

复用v53已验证的device实现：向量加载、寄存器批量解码/packing、HiF4微指数复用，
直接输出G128-major payload和FP32有效scale。A/W各一个转换kernel；所有buffer在计时前分配。
仅SM80内部接口允许候选5，且只与GEMM59组合；新增16字节对齐保护，非法组合明确拒绝。
已有输入检查、形状/index范围保护和四模式缓存语义不变。

- 原始FP16 trace直接量化为实验源格式，公共源格式准备不计时。
- 两次独立24样本四模式测量，各384条记录；第二次反转4/5的初始顺序。
- warmup50、repeats200、conversion inner100，单CUDA stream，预分配原生CUDA Event。
- conversion-only的total是每对批量摊销阶段样本之和；不是一次直接端到端测量。
- GEMM、Cold和steady total均单次直接计时；Cold含W/A转换，steady缓存W只保留A转换。
- 共享、未锁频GPU；保留所有离群/CV失败，不通过筛掉慢记录构造收益。
