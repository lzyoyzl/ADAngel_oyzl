# A100 O5/O6 group-major scale 候选验收

源码/构建 `5046507`，2026-09-29。二进制 SHA-256：
`f326244218ff8eefdfc27c63519e0e222fcdd110a64541afddeb70fb51fdbea8`。
这是合成输入诊断与候选对照，不是 24 个真实 trace 的正式验收。
旧 row-major 仍为默认；O0–O4 选择和 5090 后端不变。

## 范围

- 15 项格式参考测试、102 项 CUDA 转换检查、36 项 GEMM、24 项计时契约检查。
- 72 项 group-major 与 row-major 输出逐位对照通过；17 项非法输入拒绝。
- 两个 CTA 的原生 U4×S4、S4×S4 与 cp.async/LDGSTS 审计通过，无 S8 替代。
- 完整格式验证脚本经 memcheck：0 errors；racecheck：0 hazards/errors/warnings。
- 4096³ 一个 Gaussian FP16 样本，seed=20260929；新旧 O5/O6 加 O0/O3，
  4 模式×3 交错轮次，共 72 条原始记录。warmup50/repeats200/inner100。
- 对独立定点参考输出误差为 0；新旧布局 MSE vs 同源合成 O0 一致。

## 文件

`runs/mixed_group_major_ab_v1/` 是普通 CUDA Event 对照，保留全部计时和 GPU
快照，不筛掉 CV 失败记录。`runs/mixed_group_major_validation_v1/` 是数值与
接口验收；`runs/mixed_group_major_core_regression_v1/` 是已有整数 core 回归。
`reports/audit_mixed_group_major_v1/` 保留 ISA/资源摘要，完整 PTX/SASS 留在 A100。

`reports/ncu/mixed_group_major_v1/` 为同一二进制、同源输入的 O5 row/major
对照（9 sections；clock/cache control 均 none）；不是 Event 性能。
完整 `.ncu-rep` 在 A100 项目同路径；本目录仅归档文本导出及启动元数据。

大 CTA 存在 spill，按用户允许的小量 spill 策略验收，不是严格零 spill：
row-major REG128/STACK8；group-major REG128/STACK32。两者动态 shared 都是
68,608 字节；资源摘要的 SHARED:0 只表示静态 shared，不能解释成不用 shared。
小 CTA row/major 分别 REG90/REG91，STACK0，无 local load/store。

### 收益与限制

按同轮 row/group 延迟比取中位数，O5/O6 GEMM 分别约 1.049×/1.054×，
cold 为 1.017×/1.025×，steady 为 1.029×/1.026×。O5 steady 第三轮略慢
（速度比 0.997×），不隐去这个反例。转换反而变慢：速度比 0.890×/0.930×。
物理布局改善消费端，并不保证转换写出代价不增加。

72 条记录中 27 条至少一个阶段 CV≥3%。GPU 快照显示有另一个计算进程，
SM 时钟 1005–1410 MHz，温度 42–73°C；记录未过滤、未替换。
这些是干扰风险的证据，不足以逐条认定离群原因；暂不切换正式默认。
