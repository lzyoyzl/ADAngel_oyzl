# O3 / O7 / O8：固定流水线槽位候选（v93）

## 结论

**编译阶段淘汰，不投入 GPU 性能/MSE 测量，不替换最佳或正式默认。**
当前最佳仍为 O3 v89、O7/O8 v78 GEMM + v73 准备，RTX 5090 不变。
本轮不是新的加速成绩。

## 候选与筛选依据

保持 CTA `64×128×128`、128 线程、8 条 MMA 链、每线程 32 个 partial 寄存器、
G128 scale、全 K 整数安全界/回退、FP32 输出和转换不变。
O3 保留分组 CTA 顺序和三阶段；O7/O8 保留原两阶段。

原来每组计算动态 `group%stages`。候选每次循环显式处理一圈槽位：
O3 为 `0→1→2`，O7/O8 为 `0→1`，最后单独 drain。
只展开一圈，仍逐 G128 计算，不把多个 group 合并成一个 scale 或改变流水线 K 粒度。
每个 group 的 wait、CTA barrier、下一组预取和整数运算顺序保持一致。

测试前固定筛选规则：热循环归一化指令减少至少 5%，或寄存器减少至少 16，
且分配寄存器不增加、必要 MMA/LDSM 不增加、没有新热循环 local 读写，才进入完整 24 样本测试。
这是节省测试投入的启发式 gate，不是“有 spill 必然更慢”的普遍结论；
用户允许正确且更快的小 spill 实现，该授权未改变。

## A100 编译与同 entry 指令审计

|指标|O3 对照 → 候选|O7/O8 对照 → 候选|
|---|---|---|
|每圈 G128 数量|1 → 3|1 → 2|
|每圈静态指令|323 → 990|383 → 770|
|归一化每 G128 静态指令|323 → 330|383 → 385|
|每 G128 原生 INT4 MMA|64 → 64|64 → 64|
|每 G128 LDSM|16 → 16|16 → 16|
|候选每圈 LDL / STL|79 / 77|31 / 30|
|分配寄存器 / 线程|168 → 168|168 → 168|
|整个 entry 的 stack frame|16 → 184 B|0 → 120 B|
|候选 ptxas spill store / load|496 / 336 B|240 / 164 B|
|预设编译 gate|不通过|不通过|

两个原对照的编码 SASS 均保持完全一致；候选同一 entry 内均包含原生
`IMMA.16864.U4.S4`、`IMMA.16864.S4.S4` 和异步 `LDGSTS.BYPASS`。
CPU 检查验证 32 组顺序、prefetch/drain 和槽位复用；本地与 A100 各 102 项相关回归通过。

local 指令数来自展开的一整圈，不能直接与对照的一组混比。
ptxas 的 spill 字节是编译报告，不是测得的动态显存流量；stack 也不等于每组读写字节。
静态存活峰值或分配寄存器没增加，仍可能因指令/存活布局约束产生更多 spill。

**预期的地址简化没有转化为净工作减少：归一化指令反而增加，且新增了大量 local 操作。**
因此停止该固定候选，不继续展开因子或寄存器上限扫描；不猜测未经执行的退化百分比。
不扩大到 NCU、sanitizer、转换或端到端测试。

## 性能与 MSE 的报告边界

本轮没有新的 GPU Event、输出或 MSE 数据，不宣称候选已通过 GPU 正确性。
既有最佳实现没有修改，已确认结果继续引用此前完整 24 样本测试：

|最佳候选|此前 GEMM median ms|MSE 参考|MSE median|MSE mean|
|---|---:|---|---:|---:|
|O3 v89|0.437760|O0|0.006653010287410|0.007578847013303|
|O7 v78 + v73|0.476160|O5|0.005536172273439|0.005053635851003|
|O8 v78 + v73|0.481280|O6|0.004411084910986|0.004381379299074|

绝对延迟来自此前各自测试，不是本轮同 run 的跨后端成本分解。
必要 MMA 容量下界仍约 0.220347 ms（1410 MHz、理想重叠），不是保证可达延迟；目标尚未达到。
本轮表明只去掉动态槽位索引不能支持继续扩大这条路线，并非证明所有静态流水线方案无效。
